# SkyStep

> sky above, step below

SkyStep 是一个本地优先的六级备考网站：每天约 30 分钟，复习优先，背词、练题、写译、养一只宠物。数据留在浏览器，开源，部署在 GitHub Pages。

## 当前进度：M7（内容扩展）

M7 进行中，已可运行：

- 首次启动：选宠物、起名、12 题词汇量测试；按测试结果调整新词难度。
- 首页「天阶三步」：练习 / 新词 / 复习；新增六级词汇总进度条（已学习 / 5,233）。
- 学新词：每天选的词先全部过英→中四选一，再全部过中→英四选一，最后全部过拼写；可随时收藏或点 `Step` 跳过。
- 复习：到期卡；英→中 / 中→英 / 拼写三种方式；先回忆后显示；三档评分（不认识 / 模糊 / 认识）。
- 单词本：收藏 / 已学会 / 错词 / 自定义四个 tab；今日学习 / 今日错词 / 有笔记筛选；来源标签、笔记、收藏、标记已学会（30 天内挂起）、错词自动收集。
- 词典：18,000 条 ECDICT（MIT）词条，英译中 + 中文反查 + 词形变化 + 拼写容错；28 个核心词有例句和近反义，其余例句/短语待补。可收藏、加入复习。按需加载约 3.4 MB。
- 练习：每日练习由今日错词 + 今日收藏词生成，每个词各 1 句英译中、1 句中译英，句后括号标出必须用上的词；没有今日错词/收藏时练习为空。100 篇素材库可手动打开。逐句输入、规则批改、分数、逐句反馈、参考译文、最近批改。
- 写作 + 翻译模考：60 分钟，写作 150–200 词 + 翻译；字数评分、参考范文/译文、自评清单。
- AI 批改（可选）：设置里填 DeepSeek Base URL / 模型 / Key；默认关闭；失败自动回退规则；Key 只存本机。
- 宠物：成长阶段 / 等级 / 累计经验；饱食度、心情、金币；喂食、摸摸、改名；每日结算；商店；日 / 周 / 阶段目标；周 / 阶段奖励可领取。
- 阅读模拟：3 套 × 30 题（选词填空 10 + 长篇匹配 10 + 仔细阅读 10），40 分钟整卷、每日一练 10 题、按题型练习、套题选择、错题重练；交卷给正确率、阅读估分、分题型得分和错题解析。
- 错题排期：答错进入 1 天复习，之后 3 天、7 天；答对推进，答错重置；今日到期优先练。
- 设置：每日新词量、复习方式、词汇量重测、自动 / 白天 / 夜晚主题、AI 配置、导出 / 导入 JSON 备份、清空本地数据。
- 备份：导出卡片、复习日志、单词本、设置、写作、模考、错题排期；AI Key 不进入备份。导入会覆盖本机数据，文件上限 20 MB。
- PWA：manifest 补了中文 lang / 横竖屏 / scope；离线预缓存包含词典 JSON（约 3.4 MB）；SPA 路由有 navigate fallback。
- 无障碍：跳过导航链接、`main` landmark、焦点可见样式、`prefers-reduced-motion`、底部导航 `aria-current`、状态提示 `role="status"`。
- 蓝色 / 淡蓝色主题：白天浅蓝、夜晚稍深一点的淡蓝，不切换成深色；宠物保留暖色。
- 返回按钮：学习、复习、练习、模考、写作、商店等深入页面左上角可返回上一级。
- PWA 构建、GitHub Pages 404 回退。

## 技术栈

- Vue 3 + TypeScript + Vite
- Pinia + Vue Router
- Dexie（IndexedDB）
- `ts-fsrs`（FSRS-6）
- 原生 CSS + 设计 token
- `vite-plugin-pwa`

## 本地运行

```bash
pnpm install
pnpm dev
```

打开终端显示的地址（默认 `http://localhost:5173/`）。

构建：

```bash
pnpm build
pnpm preview
```

## 部署到 GitHub Pages

1. 创建仓库，例如 `skystep`。
2. 把 `vite.config.ts` 里的 `base` 改成 `/<仓库名>/`（当前是 `/skystep/`）。
3. 把 `dist` 发布到 GitHub Pages，或使用 GitHub Actions 构建后发布。
4. 构建脚本会自动生成 `dist/404.html`，保证前端路由刷新不 404。

## 数据

- 学习数据只存在浏览器 IndexedDB（数据库名 `skystep`）。
- 不上传、无账号、无后端。
- 设置页可以导出 / 导入 JSON 备份、清空数据。
- 词典由 `python scripts/build-ecdict.py .cache/ecdict.csv` 生成；ECDICT 源文件不入库。
- 导入会覆盖本机数据；文件上限 20 MB。
- AI Key 只存本机 `settings.ai`；导出时会排除 `apiKey`。
